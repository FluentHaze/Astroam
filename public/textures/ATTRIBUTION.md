# Planet textures

Planet and space textures by **Solar System Scope**

- Creator and original source: https://www.solarsystemscope.com/textures/
- License: **Creative Commons Attribution 4.0 International**
- License terms: https://creativecommons.org/licenses/by/4.0/
- Copyright: Solar System Scope / INOVE

Copies of ten surface maps were retrieved from Sanghel/solar-system-3d's
public/textures directory. Earth cloud and normal maps and Saturn rings were
retrieved from Qt's qt3d/tests/manual/planets-qml/images/solarsystemscope directory.
Both mirrors identify these assets as Solar System Scope textures under CC BY 4.0.
No software from these repositories was copied.

Changes by Astroam: conversion to WebP, keeping 2048 × 1024 surface maps;
Earth cloud and normal maps resized to at most 1024 pixels wide; normal map uses
lossless compression. Ring UVs sample the first disk of Qt's two-disk atlas.
The Venus texture depicts the surface below its clouds.

The source pack includes color adjustments and artistic completion of unmapped
regions. It is not a collection of live images or unmodified scientific products.

See manifest.json for exact file sizes, dimensions, source URLs, SHA-256 hashes
of source and converted files, and individual conversion notes.
