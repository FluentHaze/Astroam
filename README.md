# Astroam 星际漫游

第一轮本地原型：探索太阳系、查看天体档案、沿时间观察行星运动。

## 启动

需要 Node.js 22.12 或更新的兼容版本，以及 pnpm 11.17.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端提示的地址，默认是 http://127.0.0.1:5173/。

```sh
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm test:e2e
pnpm build
```

浏览器测试默认使用本机 Microsoft Edge。其他环境可在 `playwright.config.ts` 调整 channel，并安装对应的 Playwright 浏览器。构建输出为 `dist/`，可交由静态服务器部署；本轮没有创建远程仓库、提交代码或上线。

## 本轮功能

- 太阳、八大行星和月亮，基于 Astronomy Engine 本地计算日心位置。
- 场景旋转、缩放、平移与重置；名称、参考轨道显示开关。
- 点击或列表选择天体，查看中文介绍、平均半径、公转周期和距太阳中心的动态距离。
- 实时、模拟暂停、正反向播放、UTC 日期编辑、逐日步进和回到现在。
- 基础手机适配、键盘入口、WebGL 失败降级、上下文丢失重试、计算错误提示。

## 操作与时间规则

单击只选中，不移动镜头。左键拖动旋转，右键拖动平移，滚轮缩放；触控单指旋转，双指缩放与平移。场景聚焦后，方向键旋转，＋／－缩放，Home 重置。Esc 先关闭帮助，再关闭详情。

首次进入为实时 1 倍。编辑日期、逐日步进或从实时状态选择模拟速度后暂停；点击播放按所选倍率运行。回到现在恢复实时和 1 倍，同时保留天体选择与镜头。日期范围为 2000-01-01 至 2050-12-31，播放到边界自动暂停。

内部只保存 UTC 毫秒时间戳。主时间显示设备时区，日期编辑明确使用 UTC，以避免夏令时重复和不存在的本地时间歧义。后台停止绘制和时间推进，恢复后实时模式读取当前时钟，模拟播放从离开时刻继续，不补算后台时间。刷新回到实时；不请求定位，也不持久保存模拟时刻。

## 计算和展示边界

`HelioVector` 返回日心 J2000 赤道坐标，单位 AU。显示层旋转至 J2000 黄道参考面，再做非线性距离压缩；原始坐标和数值详情保留物理单位。月地分离单独放大到可选择的距离。**这些展示坐标不能用于月相、地面观星和日地月受光计算。**

轨道线是页面启动时刻起、按参考恒星公转周期采样一周得到的参考轨迹；没有用圆或固定角速度替代天体位置。外行星轨迹采样延伸至 UI 年份范围之外，仅用于总览参考。时间越界时不允许用户继续选择。

球体与详情预览共用 Solar System Scope 的 2K 表面贴图，补充地球云层、法线与土星环。贴图本地保存为 WebP，不依赖外站运行时请求；云层与法线限制在约 1K，以控制开销。来源素材含调色、拼接与部分缺失区域的艺术补全，并非实时影像；金星展示云层下方地表示意。预览采用固定展示光照和姿态，不表示当前地面天气、自转朝向或月相。背景星点仍为装饰。

纹理由场景与预览共享缓存，最后一个使用者卸载后延迟一秒释放；异步到达的过期结果会丢弃。加载过程中保留基础球体，失败后可在对应天体详情中重试。详情预览只在数据或材质变化时绘制，切换天体复用同一个预览 Canvas。

Worker 约每 80 ms 获取一次时间并计算位置；帧循环只更新 Three.js 对象和标签避让，不逐帧更新 React 状态。后台停止渲染，DPR 限制为 1–1.5。计算发生错误时隐藏场景并清除动态详情值，可重试恢复。
